# MediaHub SmolVLM2 Vision

Local vision and video-frame analysis plugin for MediaHub.

## Runtime

The SmolVLM2 runtime and model files are not bundled with this plugin.

Runtime dependencies and model data are managed separately by the
MediaHub runtime/tool management.

## Model

HuggingFaceTB/SmolVLM2-500M-Video-Instruct

## Capabilities

- Vision analysis
- Video-frame analysis
